# GitHub Manager Sandbox

Public test repository for validating GitHub Manager workflows without touching project repositories.

## Purpose

- Verify repository access and branch discovery.
- Verify the first commit to an empty repository.
- Verify multi-file commits using Git database objects.
- Verify download/read-back and content integrity.

## Safety

This repository is public and contains only synthetic sample files. Do not upload credentials, proprietary source code, or private project data.
